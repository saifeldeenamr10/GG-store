# GG-Store 🎮

A modern, high-performance web gaming store and management dashboard built with Vite, Vanilla JavaScript, and CSS.

## 🚀 Features

- **Storefront**: Browse, filter, and search curated games with responsive design and sleek dark mode UI.
- **Admin Dashboard**: Game inventory management, pricing updates, and catalog operations.
- **Multi-language**: Built-in internationalization (i18n) support.
- **Fast Performance**: Bundled and optimized with Vite.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript, CSS3
- **Bundler**: [Vite](https://vitejs.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/saifeldeenamr10/GG-store.git

# Navigate into directory
cd GG-store

# Install dependencies
npm install

# Run dev server
npm run dev
```

### Build for Production

```bash
npm run build
```
